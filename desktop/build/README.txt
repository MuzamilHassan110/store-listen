STORELISTEN DESKTOP RECORDER
============================

Thank you for installing StoreListen.

What this app does
- Records in-store sales conversations
- Saves captions on this PC
- Uploads audio to your StoreListen API when online
- Works offline; pending clips sync automatically

What this app does NOT do
- It does not call Google Gemini from this PC
- Keep API keys on the server only

First run
1. Enter your API URL (example: https://api.yourcompany.com)
2. Activate a license or start a 14-day trial
3. Name this device and test the microphone
4. Sign in on the dashboard so uploads can use your session token

Silent install
  StoreListen-Setup-1.0.0.exe /S
  StoreListen-Setup-1.0.0.exe /S /D=C:\Program Files\StoreListen

Portable
  StoreListen-Portable-1.0.0.exe — no installer, settings stay next to the exe / in your user profile.
